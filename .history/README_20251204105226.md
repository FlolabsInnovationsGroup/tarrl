# TARRL - Texas Advanced Robotics Research Lab

Official website for the Texas Advanced Robotics Research Lab, a remote-first Embodied AI research institute.

## Project Structure

This is a monorepo managed with pnpm workspaces:

```
TARRL/
├── backend/          # Strapi v5 CMS (Railway)
├── frontend/         # Next.js 15 App Router (Vercel)
├── scripts/          # Automation scripts
└── docs/             # Documentation
```

## Tech Stack

- **Frontend**: Next.js 15, React 19, Tailwind CSS 4, shadcn/ui, Framer Motion
- **Backend**: Strapi v5, PostgreSQL 14
- **Hosting**: Railway (backend), Vercel (frontend)
- **Package Manager**: pnpm 8+

## Quick Start

### Prerequisites

- Node.js 20+
- pnpm 8+
- Railway CLI
- Vercel CLI (optional)

### Installation

```bash
# Install dependencies
pnpm install

# Set up environment variables
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env

# Start development servers
pnpm dev
```

### Development

```bash
# Start backend (Strapi)
cd backend && pnpm dev

# Start frontend (Next.js)
cd frontend && pnpm dev
```

## Deployment

### Backend (Railway)

```bash
# Deploy Strapi to Railway
cd backend
railway up
```

### Frontend (Vercel)

```bash
# Deploy Next.js to Vercel
cd frontend
vercel deploy --prod
```
